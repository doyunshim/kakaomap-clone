# 카카오맵 클론 (검색 · 길찾기)

## 실행
```
cd kakaomap-clone
python -m http.server 5500
```
브라우저에서 http://localhost:5500 접속

## 카카오 지도 켜기
`js/config.js` 의 `KAKAO_JS_KEY` 에 JavaScript 키를 넣으면 진짜 카카오 지도 + 실제 장소 검색으로 바뀝니다.
- developers.kakao.com → 앱 만들기 → 플랫폼(Web)에 `http://localhost:5500` 등록
- 새 앱이면 카카오맵 사용 설정을 켜야 할 수 있음
- 키가 없으면 OpenStreetMap 무료 지도 + 데모 데이터로 동작

## 구현한 기능
**검색** : 자동완성, 최근 검색(삭제/전체삭제), 전체/장소/주소/버스/정류장 탭, 정확도순·인기도순, 페이지, A~O 마커,
마커 말풍선(출발/도착), 장소 상세 패널, 관련장소(지하철 출구), 저장, 이 지역 재검색

**길찾기** : 출발/도착 자동완성, 바꾸기, 초기화, 지도 우클릭으로 출발/도착 지정,
자동차(내비추천/큰길우선/최단거리/무료도로, 요금, 턴바이턴 안내, 구간 클릭 시 지도 이동),
대중교통(전체/버스/지하철/버스+지하철, 노선 뱃지, ▼ 펼치면 상세 구간),
도보·자전거(경로 3종, ▼ 상세, 자전거 고도 그래프), 경로 한눈에

## 데모 경로 (원본 화면과 동일)
- 석촌역 8호선 → 잠실역 : 대중교통 · 도보 · 자전거
- 석촌역 8호선 → 송파나루 동호 공영주차장 : 자동차

그 외 장소끼리는 거리로 시간·요금을 추정합니다.
